# 重采样库（纯 Python 3 标准库）

任意正实数倍率（不必为整数）的带限重采样，含抗混叠滤波、流式分块处理、
与高精度参照实现的逐样本对拍。

## 文件

| 文件 | 内容 |
|---|---|
| `resampler.py` | 库：`resample` / `resample_channels`（一次性）、`StreamResampler`（流式） |
| `test_resampler.py` | 22 个自测：流式逐位一致性、多声道、ratio=1、极短音频、极端倍率、频响 |
| `compare_reference.py` | 与 FFT 域理想带限参照实现对拍，输出逐样本误差 CSV |
| `error_data_down.csv` / `error_data_up.csv` | 对拍逐样本误差数据（1364 / 2965 个样本） |

## 运行方式

```bash
cd resample
python3 -m unittest -v test_resampler     # 自测（含流式一致性与边界用例）
python3 compare_reference.py              # 对拍，重新生成 error_data_*.csv
```

无第三方依赖，Python 3.8+。

## 滤波器设计

统一用**窗函数 sinc 低通 FIR**，每个输出样本在其对应的非整数输入时刻
`center = m / ratio` 处即时求值：

```
h(d) = 2·fc · sinc(2·fc·d) · blackman(d / L),   -L ≤ d ≤ L
```

- **截止频率 fc**（归一化到输入采样率，奈奎斯特 = 0.5）：
  - 降采样 `ratio < 1`：`fc = 0.5·ratio`，即输出端奈奎斯特频率——高于它的
    成分若不滤除会折叠回基带形成混叠；
  - 上采样 `ratio > 1`：`fc = 0.5`，滤除零值插补产生的频谱镜像；
  - `ratio == 1`：直通（此时任何有限长滤波器只会无谓衰减频带顶端）。
- **窗函数**：Blackman 窗 `w(t) = 0.42 + 0.5·cos(πt) + 0.08·cos(2πt)`，
  端点精确为 0，阻带衰减约 74 dB。选它而非 Kaiser 是因为标准库没有
  贝塞尔函数，Blackman 用 `math.cos` 即可精确求值，且 74 dB 阻带对
  16-bit 音频（动态范围约 96 dB 中的信号成分）已足够。
- **长度**：sinc 每侧保留 32 个过零点，`L = 32 / (2·fc)` 输入样本
  （ratio=0.5 时 L=64；极端降采样会变大，故以 `max_half_length=8192`
  封顶，可调）。每个输出样本再按该相位的权重和归一化，保证任意分数
  延迟下直流增益恒为 1。

## 相位处理

滤波器关于 `d=0` 对称，是**零相位（线性相位、群延迟为 0）**设计：
输出样本 `m` 严格对齐输入连续时刻 `m/ratio`，不引入样本延迟，多声道
间也不会产生相对相位偏移。实现上不做因果延迟补偿，而是等滤波窗口
所需的输入样本全部到齐后再计算该输出样本（流式下天然满足）。

## 流式处理与块边界

`StreamResampler.process(chunk)` 只产出"整个滤波窗口都已到达"的输出
样本，历史输入按窗口下界滑动丢弃；`flush()` 时信号两端之外严格按 0
处理（理想带限模型，不做增益补偿，因此**永不放大**；代价是结尾约
一个滤波器半长 L·ratio 个输出样本存在自然衰减/Gibbs 振铃，这是所有
零相位带限重采样的固有特性）。

每个输出样本的卷积求和顺序与分块方式无关，因此**分块结果与整体处理
逐位（bit-exact）相同**——测试用 `==` 而非近似比较验证，块大小序列
覆盖 `[1]`、`[7]`、`[3,5,8]`、`[64,13,1]`、无理数倍率等。块边界
不存在任何拼接/交叉淡化逻辑，从原理上杜绝边界爆音；另有专门的
跳变信号测试（`test_sample_jump_at_boundary`）在跳变沿附近随机切分
35 次验证。

## 对拍方法与误差来源

参照实现（`compare_reference.py`）：信号两端补零后做 **FFT 域理想带限
重采样**——降采样直接截断频谱（理想低通），上采样谱中插零。FFT 用
标准库 `cmath` 实现：基-2 迭代 + Bluestein chirp-z（支持任意长度，
任意分数倍率的输出长度不必是 2 的幂），往返误差 ~1e-14，相对被测
实现完全独立。

对拍要点：输出长度取整使**有效倍率** `n_out/n_in` 与名义倍率偏差
≤ 0.5/n_in，两边必须使用同一有效倍率，否则时间映射不同、相位误差
随样本索引线性累积（对拍脚本内自动处理）。

实测误差（测试信号为 3 个正弦之和，能量全部位于通带，比较区间剔除
两端边界瞬态）：

| 用例 | max | RMS | 折合 |
|---|---|---|---|
| 降采样 0.7（1364 样本） | 1.03e-3 | 1.51e-4 | -60 dB / -76 dB |
| 上采样 1.5（2965 样本） | 2.52e-3 | 2.48e-4 | -52 dB / -72 dB |

逐样本数据见 `error_data_down.csv` / `error_data_up.csv`
（列：输出索引、对应输入时刻、参照值、实测值、绝对误差）。

误差来源（按贡献排序）：

1. **sinc 截断 + 窗函数过渡带/波纹**（主导）：理想 sinc 无限长，32 个
   过零点的 Blackman 截断在通带边缘（约 0.8·fc 以上）产生 ripple，
   越靠近 fc 误差越大——上采样用例中整数相位点（无需插值）误差
   ~1e-13，分数相位点 ~3e-4，即为此因。增大 `zero_crossings` 可
   线性压低该误差。
2. **阻带残余**：Blackman 阻带约 -74 dB，被滤除频段仍有微量泄漏
   （实测 0.45→0.5 降采样混叠残余 RMS 2.8e-7，约 -111 dB，远优于
   理论阻带，因测试频率落在阻带深处）。
3. **浮点舍入**：双精度卷积 ~1e-13 量级，可忽略。

注意：比较区间刻意剔除了两端各约一个滤波器半长的边界瞬态——端点
之外按 0 处理的假设在边界处与"信号本应延续"不符，该区域的偏差是
模型假设而非实现误差。

## 边界用例覆盖（test_resampler.py）

- **极短音频**：空输入、1 个样本、2 个样本、短于滤波器长度（3 样本），
  上/下采样均验证长度、有限性、不放大与流式一致；
- **单声道与多声道**：立体声两声道内容不同，验证声道独立性、与单声道
  结果一致、分块逐位一致；
- **倍率 1**：整体与流式均逐位直通；
- **极端倍率**：1/64、1/100、64、100、0.999、1.001，验证输出长度、
  有界性与流式逐位一致；
- **频响**：通带正弦保真（误差 < 2e-3，实测 ~3e-6）、超奈奎斯特成分
  混叠抑制（残余 RMS < 3e-3，实测 ~3e-7）、上采样镜像抑制。

## 性能说明

纯 Python 卷积，每个输出样本约 `2L` 次乘加（L 随降采样比增大）。
适合中小规模与验证用途；大规模实时场景应换用 numpy/C 实现，但算法
与参数可直接平移。
