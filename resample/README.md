# 任意倍率音频重采样器（纯标准库 Python 3）

支持任意非整数倍率、多声道、流式分块处理的重采样库，降采样自带抗混叠滤波。
仅依赖 Python 标准库（`math` / `fractions` / `unittest`）。

## 文件

| 文件 | 说明 |
|---|---|
| `resampler.py` | 交付库：`Resampler`（流式）、`resample`、`resample_mono` |
| `reference.py` | 参照实现：基于 DFT 的理想带限重采样（仅用于对拍） |
| `compare.py` | 对拍脚本：逐样本误差表 + max/RMS/mean 统计，写 CSV |
| `test_resampler.py` | 17 项测试：流式一致性、边界、抗混叠、相位、对拍 |
| `compare_output.txt` | 一次完整对拍运行输出 |
| `error_data/*.csv` | 各用例稳态区逐样本误差数据 |

## 滤波器设计

**核函数**：加 Blackman 窗的 sinc 低通（windowed-sinc FIR）：

```
h(t) = 2·fc · sinc(2·fc·t) · blackman(t / W),   |t| ≤ W
```

- **截止频率** `fc = 0.5 · min(1, ratio) · 0.98`（单位：周期/输入采样）。
  降采样（ratio<1）时 fc 收缩到新奈奎斯特的 98%，这就是抗混叠低通；
  升采样时 fc 取输入奈奎斯特的 98%，抑制镜像。
- **窗函数**：Blackman 窗，阻带衰减约 −74 dB，把截断 sinc 的吉布斯纹波
  压到该量级。核半径 `W = zero_crossings / (2·fc)`，即两侧各保留
  `zero_crossings`（默认 16，对拍用 32）个 sinc 过零点——降采样越多，
  核自动越宽，过渡带越窄，抗混叠越充分。
- **增益**：`2·fc·sinc(2·fc·t)` 的积分为 1，直流增益为 1（测试验证
  常数信号稳态误差 < 1e-4）。

**相位处理**：核关于中心偶对称（零相位，等价于群延迟已补偿的线性相位
FIR）。第 n 个输出样本对应输入时间 `t_n = n / ratio`，滤波器以 `t_n`
为中心对称取值，输出与输入时间轴严格对齐、无群延迟。测试
`TestPhase` 验证正弦峰值位置按倍率精确对齐（误差 < 1 个输出样本）。

**端点**：信号在 `[0, N)` 之外按零处理，两端各有约 `W`（输入采样）的
过渡区，这是有限长滤波的固有边界效应；对拍统计均跳过该区。

## 流式处理

`Resampler` 内部维护输入帧缓冲与绝对序号：

- `process(frames)` 可任意分块喂入；只有右窗缘已落入已收到数据的输出
  样本才会产出，其余等更多输入；
- `flush()` 结束输入，用零填充产出全部剩余输出；
- 每个输出样本的计算只依赖其绝对序号，与分块方式无关，因此分块结果
  与一次性处理**逐位（bit-exact）一致**（`TestStreaming` 用 1/7/100/
  混合块长验证 `==` 相等），块边界不可能产生爆音；
- 已消费的历史帧即时丢弃，缓冲占用 O(滤波器长度)，与流长无关。

## 对拍与误差数据

参照实现（`reference.py`）：零填充 → DFT（任意长度，基-2 + Bluestein）
→ 频域按目标长度补零/截断（降采样即理想矩形低通）→ IDFT。倍率用
`Fraction` 取精确有理数，保证输出样本 i 恰好对应输入位置 i/ratio，
无累积相位漂移。两端实现独立（时域窗函数法 vs 频域理想低通）。

信号峰值约 1.0，稳态区绝对误差（`python3 compare.py`，完整逐样本数据
见 `error_data/*.csv` 与 `compare_output.txt`）：

| 用例 | 倍率 | max 误差 | RMS 误差 |
|---|---|---|---|
| 48k → 44.1k | 0.9188 | 9.0e-04 | 1.1e-04 |
| 44.1k → 48k | 1.0884 | 1.8e-03 | 1.3e-04 |
| 48k → 16k | 1/3 | 1.2e-03 | 2.1e-04 |
| 8k → 48k | 6 | 2.2e-03 | 2.2e-04 |
| 48k → 1k（极端降） | 1/48 | 2.1e-03 | 1.3e-03 |
| 1k → 48k（极端升） | 48 | 2.1e-03 | 5.1e-04 |

**误差来源**（按贡献排序）：

1. 截断窗的残余纹波：Blackman 窗阻带约 −74 dB，带内纹波与阻带泄漏
   均在 1e-4 量级，是稳态误差主体；
2. 过渡带形状差异：被测库过渡带有限宽（约 ±1/W），参照为理想矩形，
   过渡带内的信号分量两者响应不同（对拍信号已避开过渡带）；
3. 参照实现自身的端部泄漏：零填充信号的周期延拓在两端引入误差，
   已通过跳过边缘区隔离；
4. 双精度浮点舍入：1e-15 量级，可忽略。

增大 `zero_crossings`（如 32→64）可继续压低第 1 项，代价是计算量
线性增长。

## 边界用例覆盖（test_resampler.py，17 项全过）

- **极短音频**：0 / 1 / 2 / 3 / 5 个样本 × 升/降/极端倍率，输出有限、
  不崩溃；空输入 flush 产出空；
- **倍率 1**：逐位直通（流式同样直通）；
- **单声道与多声道**：3 声道结果与逐声道单声道处理逐位一致；
- **极端倍率**：48k→1k（带内增益保持 ±0.01，带外分量混叠抑制 > 55 dB）、
  1k→48k（波形幅度保持 ±0.005）；
- **流式一致性**：多种块长分块 vs 整体处理逐位相等（含极端倍率）；
- **相位**：零群延迟验证；**直流**：常数信号保持；
- **对拍**：降/升/近 1 倍率三组，max < 5e-3、RMS < 2e-3。

## 运行方式

```bash
cd resample
python3 test_resampler.py     # 全部测试（约 3 秒）
python3 compare.py            # 对拍，打印误差表并写 error_data/*.csv
```

API 示例：

```python
from resampler import Resampler, resample_mono

# 一次性
y = resample_mono(x, 48000, 44100)

# 流式（任意分块）
r = Resampler(48000, 44100, channels=2)
out = []
for chunk in chunks:                 # chunk: [(l, r), ...]
    out += r.process(chunk)
out += r.flush()

# 更高精度（更长的滤波器）
y = resample_mono(x, 48000, 44100, zero_crossings=64)
```
