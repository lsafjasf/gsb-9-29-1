# 权重口径说明

## 1. 打分公式

```
score(t, d) = tf(t, d) × idf(t) × pos_weight(t, d) [× phrase_bonus]
```

| 因子 | 口径 |
|---|---|
| `tf` | 词在文档内的**原始出现次数**，不取对数、不归一化 |
| `idf` | `log((N + 1) / (df + 1)) + 1`，N 为语料文档数，df 为出现该词的文档数。**单文档语料时 idf 恒为 1**，退化为 TF × 位置权重 |
| `pos_weight` | 取该词**所有出现位置中的最大区域权重**（见下表） |
| `phrase_bonus` | 多词短语 × 1.5：英文 bigram、中文 ≥4 字 n-gram。中文 3 字词（如「过拟合」）**不加成**，避免「胀预期」类 3 字碎片被放大 |

## 2. 位置权重

文档结构解析口径：首个非空行 = 标题；空行分段；每段第一句 = 段首句；最后一段 = 结尾段。

| 区域 | 权重 |
|---|---|
| 标题 | 2.0 |
| 段首句 | 1.5 |
| 结尾段 | 1.3 |
| 正文 | 1.0 |

同一句命中多个区域时取较高权重；同一词多次出现时取各次中的最大权重。

## 3. 候选生成与停用词

- **英文**：小写化后按 `[A-Za-z0-9]+([-'][A-Za-z0-9]+)*` 切词；停用词表过滤；纯数字、单字母不成候选。
- **中文（无分词）**：先按**停用字**把连续汉字切段，再在段内取 **2~6 字 n-gram** 作为候选，单字不成候选。
- 停用字表只收「的、了、和、与、及……」等几乎不出现在关键词内部的虚字。
  **已知局限**：字级停用表会误伤「目的（的）、要求（要）、会议（会）、中国（中）」等含虚字的词，
  因此刻意不收「过/正/据/通/行」等高频词内字（否则会切碎「过拟合、正则、数据、通胀、银行」）。

## 4. 短语合并判据

### 英文（bigram 合并）
两个实词在同一句子内**严格相邻**（中间无标点、无停用词），且：
1. 共现次数 ≥ 2（超短文档 ≥ 1）；
2. 包含度 `count(pair) / min(count(w1), count(w2)) ≥ 0.5`（两词多半结伴出现）。

合并后短语作为独立候选打分（自带 tf/df/位置，×1.5 加成）。
**吸收规则**：若某单词存在合法短语使 `count(phrase) ≥ 0.5 × count(word)`，该单词不再单独输出
（如「climate change」成立后不再输出单独的「climate」）。
**例外**：超短文档中 tf=1 的短语也会合法，此时不做吸收，避免单词被一次性短语误吞。

### 中文（n-gram 吸收）
长词本身就是短语。短 n-gram A 满足任一条件即被舍弃（B 为包含 A 的更长候选）：
1. **覆盖吸收**：所有 `tf(B) ≥ 2` 的 B 的词频之和 ≥ `0.8 × tf(A)`；
2. **单一强吸收**：存在 `tf(B) ≥ 2` 且 `tf(B) ≥ 0.6 × tf(A)`。

例：「量子」(tf=3) 被「量子计算」(tf=2) 强吸收；「睡眠」(tf=6) 被「睡眠质量+深度睡眠」(3+2 ≥ 4.8) 覆盖吸收；
「利率」(tf=3) 的更长候选均 tf=1，不吸收，保留。

**长碎片过滤**：≥5 字的 n-gram 在任何文档（含超短文档）都要求 `tf ≥ 3`——
两个词偶然相邻两次很常见，相邻三次以上才可信（如「公开市场操作」tf=3 保留，「缓解过拟合」tf=2 丢弃）。

## 5. 超短文档降级

文档 token 数（英文词数 + 中文字数）< 50 时视为超短文档：
- `min_tf` 从 2 降为 1（短语共现阈值同步降为 1）；
- 不做英文单词吸收（见上）；
- ≥5 字中文 n-gram 仍要求 tf ≥ 3，不受降级影响。

## 6. 排序与平局

按分数降序；同分时依次比较：词频高者优先 → 词更长（更具体）者优先 → 字典序。
